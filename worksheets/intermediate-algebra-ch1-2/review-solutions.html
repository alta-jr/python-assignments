Part A — Isolation§1.1

  1. 2x−13 − x+45 = 2

    Multiply both sides by 15 (the LCD) to clear fractions:  5(2x − 1) − 3(x + 4) = 30.

    Expand:  10x − 5 − 3x − 12 = 30  ⇒  7x − 17 = 30  ⇒  7x = 47.

    x = 47/7

  2. √3x+1 = x − 3

    Square both sides:  3x + 1 = x2 − 6x + 9  ⇒  x2 − 9x + 8 = 0  ⇒  (x − 1)(x − 8) = 0.

    Candidates x = 1 and x = 8. Squaring can create false solutions, so check both:

    • x = 1:  √4 = 2 but x − 3 = −2.  Extraneous — the radical is never negative.
    • x = 8:  √25 = 5 and x − 3 = 5.  Valid.

    x = 8

  3. 3x−2 = 5x+4

    Neither denominator may be zero, so x ≠ 2 and x ≠ −4. Cross-multiply:

    3(x + 4) = 5(x − 2)  ⇒  3x + 12 = 5x − 10  ⇒  22 = 2x.

    x = 11  11 is neither excluded value, so it is legitimate.

  4. | 2x − 5 | = 7

    An absolute value equals 7 when the inside is 7 or −7, so split into two equations:

    2x − 5 = 7 ⇒ x = 6     or     2x − 5 = −7 ⇒ x = −1.

    x = 6 or x = −1

  5. xa + xb = 1

    Multiply by ab:  bx + ax = ab. Factor the variable you are solving for:  x(a + b) = ab.

    x = aba + b

    This requires a ≠ 0 and b ≠ 0 (the original fractions) and a + b ≠ 0 (the final division). If a + b = 0 the equation becomes 0 = ab, which has no solution for x.

  6. A = P(1 + rt), solve for t

    Divide by P:  A/P = 1 + rt. Subtract 1:  rt = A/P − 1 = (A − P)/P. Divide by r:

    t = A − PPr  (P ≠ 0, r ≠ 0)

Part B — Substitution & Elimination§1.2–1.3

  1. y = 2x − 3,  3x + 2y = 8

    Substitute the first into the second:  3x + 2(2x − 3) = 8  ⇒  7x − 6 = 8  ⇒  x = 2.

    Back-substitute:  y = 2(2) − 3 = 1. Check in equation 2: 3(2) + 2(1) = 8 ✓

    (x, y) = (2, 1)

  2. 4x − 3y = 18,  3x + 5y = −1

    Eliminate y: multiply the first by 5 and the second by 3 so the y-terms cancel.

    20x − 15y = 90  and  9x + 15y = −3. Add:  29x = 87  ⇒  x = 3.

    Then 3(3) + 5y = −1  ⇒  5y = −10  ⇒  y = −2. Check: 4(3) − 3(−2) = 18 ✓

    (x, y) = (3, −2)

  3. x + y + z = 6,  2x − y + 3z = 9,  x − 2y + 4z = 9

    Eliminate x from the last two using the first. (2) − 2×(1):  −3y + z = −3.

    (3) − (1):  −3y + 3z = 3.

    Subtract those two:  2z = 6  ⇒  z = 3. Then −3y + 3 = −3  ⇒  y = 2, and x = 6 − 2 − 3 = 1.

    Check in (2): 2(1) − 2 + 3(3) = 9 ✓   and in (3): 1 − 4 + 12 = 9 ✓

    (x, y, z) = (1, 2, 3)

  4. 2x − 6y = 5,  −3x + 9y = 1

    Multiply the first by 3 and the second by 2:  6x − 18y = 15  and  −6x + 18y = 2. Add:  0 = 17, which is false.

    No solution

    Both equations have slope 1/3 (y = x/3 − 5/6 and y = x/3 + 1/9) but different intercepts: the lines are parallel and never meet. A contradiction like 0 = 17 always means parallel lines; an identity like 0 = 0 would mean the same line twice.

  5. x2 + y2 = 25,  y = x + 1

    Substitute:  x2 + (x + 1)2 = 25  ⇒  2x2 + 2x − 24 = 0  ⇒  x2 + x − 12 = 0  ⇒  (x + 4)(x − 3) = 0.

    x = 3 gives y = 4;  x = −4 gives y = −3. Both satisfy x2 + y2 = 25.

    (3, 4) and (−4, −3)

    The circle of radius 5 centered at the origin meets the line y = x + 1 in exactly these two points.

  6. x + y = 5,  y + z = 8,  z + x = 9

    Add all three:  2(x + y + z) = 22  ⇒  x + y + z = 11.

    Subtract each original equation from that total:  z = 11 − 5 = 6,  x = 11 − 8 = 3,  y = 11 − 9 = 2.

    (x, y, z) = (3, 2, 6)

Part C — Lines & Graphing§1.4

  1. Line through (−2, 5) and (4, −7)

    Slope:  m = −7 − 54 − (−2) = −126 = −2.

    Point-slope with (−2, 5):  y − 5 = −2(x + 2)  ⇒  y = −2x + 1.

    y = −2x + 1    y-intercept (0, 1);  x-intercept: 0 = −2x + 1 ⇒ (1/2, 0).

  2. Intersection of 2x + 3y = 12 and y = x − 1

    Substitute:  2x + 3(x − 1) = 12  ⇒  5x = 15  ⇒  x = 3, so y = 2.

    (3, 2)

    Graph check: 2x + 3y = 12 has intercepts (6, 0) and (0, 4); y = x − 1 passes through (0, −1) and (1, 0). The two lines cross at (3, 2).

  3. The line 3x − 4y = 8

    (a) −4y = −3x + 8  ⇒  y = 34x − 2, slope m = 3/4.

    (b) Parallel means equal slope; through (0, −1) the intercept is −1:  y = 34x − 1

    (c) Perpendicular means the negative reciprocal slope, −4/3:  y = −43x − 1

  4. Ticket problem

    Let a = adult tickets and s = student tickets. Then a + s = 250 and 12a + 7s = 2300.

    Substitute s = 250 − a:  12a + 7(250 − a) = 2300  ⇒  5a + 1750 = 2300  ⇒  a = 110.

    So s = 140. Check: 12(110) + 7(140) = 1320 + 980 = 2300 ✓

    110 adult, 140 student

  5. Rectangle with perimeter 54

    Let w be the width; then the length is 2w + 3. Perimeter:  2(w + 2w + 3) = 54.

    6w + 6 = 54  ⇒  w = 8, so the length is 19. Check: 2(8 + 19) = 54 ✓

    width 8 cm, length 19 cm

Part D — Function Basics§2.1

  1. Domains

    (a) x2 − 4x − 5 = (x − 5)(x + 1), which is 0 at x = 5 and x = −1.
    (−∞, −1) ∪ (−1, 5) ∪ (5, ∞)  The numerator's zero at x = 3 does not restrict anything.

    (b) Need 7 − 2x ≥ 0 ⇒ x ≤ 7/2.  (−∞, 7/2]

    (c) The radical needs x + 4 ≥ 0 and the denominator needs x + 4 ≠ 0, so x > −4.  (−4, ∞)

  2. f(x) = 2x2 − x + 1

    f(−3) = 2(9) − (−3) + 1 = 18 + 3 + 1 = 22

    f(a + 1) = 2(a + 1)2 − (a + 1) + 1 = 2a2 + 4a + 2 − a − 1 + 1 = 2a2 + 3a + 2

    f(−x) = 2x2 + x + 1  — not equal to f(x) or to −f(x), so this function is neither even nor odd.

  3. Range of x2 − 4x + 7

    x2 − 4x + 7 = (x2 − 4x + 4) + 3 = (x − 2)2 + 3.

    A square is never negative, so the output is at least 3, with equality exactly at x = 2; every value above 3 is hit as well.

    [3, ∞)

  4. Difference quotient for f(x) = x2 − 5x

    f(x + h) = (x + h)2 − 5(x + h) = x2 + 2xh + h2 − 5x − 5h.

    Subtract f(x) = x2 − 5x:  2xh + h2 − 5h = h(2x + h − 5). Divide by h ≠ 0:

    2x + h − 5

  5. Which are functions of x?

    (a) Yes — each input 1, 2, 3 appears once. (Two inputs sharing the output 2 is fine.)

    (b) No — the input 1 is paired with both 2 and 3.

    (c) No — x = 4 gives y = 2 and y = −2; it fails the vertical line test.

    (d) Yes — every x produces exactly one y.

Part E — Graphs of Functions§2.2

  1. y = −2| x − 3 | + 4

    Read it from the inside out: shift right 3; stretch vertically by a factor of 2; reflect across the x-axis (the minus sign); shift up 4.

    Vertex (3, 4), opens downward, with sides of slope −2 and +2. Useful check points: (2, 2) and (4, 2); x-intercepts at x = 1 and x = 5.

  2. Transformed points from (2, −5)

    (a) y = f(x − 4) + 1: input shifts right 4, output up 1 → (6, −4)

    (b) y = −3f(x): same input, output × (−3) → (2, 15)

    (c) y = f(2x): need 2x = 2, so x = 1 → (1, −5)

    (d) y = f(−x): need −x = 2, so x = −2 → (−2, −5)

    Changes inside the function affect x and act in reverse; changes outside affect y and act as written.

  3. y = √x + 2 − 3

    The basic square-root curve shifted left 2 and down 3.

    Domain [−2, ∞), range [−3, ∞), endpoint (−2, −3)

    Plot (−2, −3), (−1, −2), (2, −1), (7, 0).

  4. Even, odd, or neither

    (a) f(−x) = −x3 + 4x = −f(x) → odd (symmetric about the origin).

    (b) g(−x) = x4 − 3x2 + 1 = g(x) → even (symmetric about the y-axis).

    (c) h(−x) = x2 − x, which is neither h(x) nor −h(x) → neither.

Part F — Composition§2.3

  1. f(x) = 2x − 1,  g(x) = x2 + 3

    f(g(x)) = 2(x2 + 3) − 1 = 2x2 + 5

    g(f(x)) = (2x − 1)2 + 3 = 4x2 − 4x + 4

    f(g(2)): g(2) = 7, then f(7) = 13.   g(f(2)): f(2) = 3, then g(3) = 12.

    Composition is not commutative — order matters.

  2. (f ∘ g)(x) with f(x) = 1/(x − 2), g(x) = √x

    (f ∘ g)(x) = 1√x − 2

    Two restrictions: x must be in the domain of g, so x ≥ 0; and g(x) must be in the domain of f, so √x ≠ 2, i.e. x ≠ 4.

    Domain: [0, 4) ∪ (4, ∞)

  3. h(x) = (3x + 1)5

    Take the inside expression as g and the outside operation as f:

    g(x) = 3x + 1 and f(x) = x5  Other splits work too — for instance g(x) = 3x with f(x) = (x + 1)5 — but this is the natural one.

  4. Repeated composition of f(x) = 2x − 3

    f(f(x)) = 2(2x − 3) − 3 = 4x − 9

    f(f(f(x))) = 2(4x − 9) − 3 = 8x − 21

    Four applications give 2(8x − 21) − 3 = 16x − 45. In general n applications give 2nx − 3(2n − 1).

Part G — Inverse Functions§2.4

  1. f(x) = (2x − 5)/3

    Write y = (2x − 5)/3, swap the roles, and solve for the new output: 3y = 2x − 5 ⇒ x = (3y + 5)/2.

    f−1(x) = 3x + 52

    Check: f(f−1(x)) = (2 · 3x+52 − 5)/3 = (3x + 5 − 5)/3 = x ✓

  2. f(x) = 4 − x3

    y = 4 − x3  ⇒  x3 = 4 − y  ⇒  x = 3√4 − y.

    f−1(x) = 3√4 − x  Domain and range are all real numbers — odd powers are one-to-one, so no restriction is needed.

  3. f(x) = (x + 1)/(x − 3)

    y(x − 3) = x + 1  ⇒  xy − 3y = x + 1. Collect the x terms:  x(y − 1) = 3y + 1.

    f−1(x) = 3x + 1x − 1,  x ≠ 1

    The excluded input 1 of f−1 is exactly the value f never outputs, and the excluded input 3 of f is the value f−1 never outputs. Domain and range swap.

  4. f(x) = x2 − 6x + 5 on x ≥ 3

    Complete the square:  f(x) = (x − 3)2 − 4. On x ≥ 3 the function is increasing, so it is one-to-one and invertible there.

    y = (x − 3)2 − 4 ⇒ (x − 3)2 = y + 4 ⇒ x − 3 = √y + 4  (the positive root, since x − 3 ≥ 0).

    f−1(x) = 3 + √x + 4,  domain x ≥ −4  (the range of f is [−4, ∞)).

  5. Short answers

    (a) f−1(8) = 3 — the inverse undoes f, sending outputs back to inputs.

    (b) 5 — (f−1 ∘ f)(x) = x for every x in the domain of f.

    (c) It is not one-to-one: g(2) = g(−2) = 4, so an inverse would have to send 4 to two different values. It fails the horizontal line test. (Restricting to x ≥ 0 fixes this.)

    (d) It is the reflection of the graph of f across the line y = x; every point (a, b) on f becomes (b, a) on f−1.

Challenge Problems★

  1. √x + 5 + √x = 5

    Isolate one radical first:  √x + 5 = 5 − √x. Square both sides:

    x + 5 = 25 − 10√x + x  ⇒  10√x = 20  ⇒  √x = 2  ⇒  x = 4.

    Check: √9 + √4 = 3 + 2 = 5 ✓

    x = 4  Isolating before squaring is what keeps the algebra linear; squaring the sum directly leaves a cross term.

  2. f(x) = (2x + 3)/(x − 2)

    f(f(x)) = 2 · 2x+3x−2 + 32x+3x−2 − 2. Multiply numerator and denominator by (x − 2):

    = 2(2x+3) + 3(x−2)(2x+3) − 2(x−2) = 4x + 6 + 3x − 62x + 3 − 2x + 4 = 7x7 = x ✓

    f is its own inverse: f−1 = f  Its graph is symmetric across the line y = x. Such functions are called involutions.

  3. f(x) + 2f(1/x) = 3x

    Substituting x = 2:  f(2) + 2f(1/2) = 6.   Substituting x = 1/2:  f(1/2) + 2f(2) = 3/2.

    Two equations in the two unknowns f(2) and f(1/2). Double the second and subtract the first:  3f(2) = 3 − 6 = −3.

    f(2) = −1

    In general, replacing x by 1/x gives f(1/x) + 2f(x) = 3/x. Doubling that and subtracting the original eliminates f(1/x):  3f(x) = 6/x − 3x.

    f(x) = 2x − x  Check: f(2) = 1 − 2 = −1 ✓

  4. Range of f(x) = (2x + 1)/(x − 3)

    Ask which y are achievable:  y = 2x+1x−3 ⇒ y(x − 3) = 2x + 1 ⇒ x(y − 2) = 3y + 1.

    If y ≠ 2 we can solve: x = (3y + 1)/(y − 2), so that y is attained. If y = 2 the equation becomes 0 = 7, which is impossible.

    Range: all real numbers except 2  2 is the ratio of the leading coefficients — the horizontal asymptote.
